# 演示后回滚清单

> 本次为现场演示提速，改动仅用于演示，演示完必须回滚。
> 演示目标：调模型后快速看到调用日志 + 成本/效能统计效果。

## 改动总览

| 位置 | 演示值 | 原值 | 作用 |
|------|--------|------|------|
| `apps/celery_app.py` → `sync-llm-logs` | `1.0`（秒） | `settings.llm_log_sync_interval_minutes * 60` | SpendLogs → 平台 DB 秒级落表 |
| `apps/celery_app.py` → `efficiency-aggregate` | `30.0`（秒） | `5 * 60`（5 分钟） | 自动重聚合 `cost_summary_daily` 兜底 |
| `ui/packages/admin/src/views/logs/tabs/LlmLogsTab.vue` | 新增 1 秒静默轮询 | 无自动刷新 | 日志页秒级刷新，不闪屏 |

## 回滚步骤

### 1. 后端 `apps/celery_app.py`

#### `sync-llm-logs` 改回原值

```python
# 演示值（删掉）
"schedule": 1.0,

# 改回
"schedule": settings.llm_log_sync_interval_minutes * 60,
```

实际定位（`beat_schedule` 字典内）：

```python
"sync-llm-logs": {
    "task": "llm_log.sync",
    "schedule": settings.llm_log_sync_interval_minutes * 60,  # 演示时改成了 1.0
},
```

#### `efficiency-aggregate` 改回原值

```python
"efficiency-aggregate": {
    "task": "efficiency.aggregate",
    "schedule": 5 * 60,  # 演示时改成了 30.0
},
```

### 2. 前端 `ui/packages/admin/src/views/logs/tabs/LlmLogsTab.vue`

删掉演示期新增的轮询逻辑，恢复原状：

- `import` 行去掉 `onUnmounted`，恢复为：

  ```ts
  import { computed, ref, watch, onMounted } from 'vue'
  ```

- 删除 `silentRefresh` 函数

- 删除 `buildLogQuery` 函数

- `loadLogs` 恢复为内联 query（把 `buildLogQuery()` 调用展开回原参数对象）

- 删除 `refreshTimer` 变量与 `onUnmounted` 整块

- `onMounted` 恢复为：

  ```ts
  onMounted(() => {
    applyRouteFilters()
    loadFilters()
    loadLogs()
  })
  ```

## 生效方式

- 后端：重启 celery worker + beat（beat 进程读 schedule，不重启不生效）
- 前端：Vite HMR 自动热重载，存盘即生效

## 验证回滚成功

- 日志页不再每秒自动出新行（需手动点"查询"才刷新）
- 成本/效能页点"刷新"按钮仍可用（该按钮是 on-demand 聚合，与 beat 无关，回滚后保留）
- celery beat 日志确认 `sync-llm-logs` 恢复分钟级、`efficiency-aggregate` 恢复 5 分钟级
